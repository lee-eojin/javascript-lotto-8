# javascript-lotto-precourse

간단한 로또 발매기

## 프로젝트 구조

```

│   ├── LottoGenerator.js
│   └── PrizeCalculator.js

└── index.js
```

## 기능 목록

### 입력
- 구입 금액 입력 (1,000원 단위)
- 당첨 번호 입력 (중복되지 않는 6개 숫자)
- 보너스 번호 입력 (1개 숫자)

### 로또 발행
- 구입 금액만큼 로또 발행
- 로또 한 장당 1~45 중 중복 없는 숫자 6개 자동 생성
- 생성된 로또 번호는 오름차순으로 정렬
- 생성된 로또 목록 출력

### 당첨 확인
- 각 로또와 당첨 번호 비교
- 일치 개수 확인
- 보너스 번호 일치 여부 확인
- 등수 판정
  - 6개 일치: 1등 (2,000,000,000원)
  - 5개 일치 + 보너스: 2등 (30,000,000원)
  - 5개 일치: 3등 (1,500,000원)
  - 4개 일치: 4등 (50,000원)
  - 3개 일치: 5등 (5,000원)

### 결과 출력
- 등수별 당첨 개수 출력
- 총 수익률 계산 및 출력
  - 수익률 = (총 당첨 금액 / 구입 금액) * 100
  - 소수점 둘째 자리에서 반올림

### 예외 처리
- 구입 금액이 1,000원 미만이면 예외 발생
- 구입 금액이 1,000원으로 나누어떨어지지 않으면 예외 발생
- 로또 번호가 1~45 범위를 벗어나면 예외 발생
- 로또 번호에 중복이 있으면 예외 발생
- 당첨 번호가 6개가 아니면 예외 발생
- 보너스 번호가 당첨 번호와 중복되면 예외 발생
- 숫자가 아닌 값이 입력되면 예외 발생
- 빈 값이나 공백이 입력되면 예외 발생

```
[1, 3, 5, 14, 22, 45]

당첨 통계
3개 일치 (5,000원) - 1개

```
